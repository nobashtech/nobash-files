# Nobash File Integrity — WordPress.org submission candidate

This folder is a **separate, read-only plugin**, not a limited mode of the Nobash Files file manager. It has its own plugin slug `nobash-file-integrity` and version number.

WordPress.org may reject a new file-manager plugin offering arbitrary code edits. For this reason, the WordPress.org candidate has **no file browser, file editor, upload, download, archive extraction, repair, or other file mutation**. It offers a narrower file integrity diagnostic product.

The candidate has passed PHP lint and an isolated scanner smoke test only. It has **not** been tested on a running WordPress 7.1 site or passed an official Plugin Check rerun. Do not represent it as approved or guaranteed to be accepted.
